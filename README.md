#  Proyecto DAW2 Óptica Microservicios

Proyecto académico de una aplicación para la gestión de una óptica, usando microservicios con Spring Boot, arquitectura hexagonal y seguridad con JWT/OAuth2.

## Tecnologías

- Java 17
- Spring Boot 3 (Web, Data JPA, Security)
- Spring Cloud (Eureka, Config, Gateway)
- PostgreSQL
- Maven/Gradle
